# Writer 代次交接保护

## 目的

Writer 接管或过期时，旧有限任务可能尚未退出。新 Writer 可以立即取得租约，但其涉及重叠物理根目录的有限写入任务必须等待旧代次的实际操作结束。常驻 Process 独立于 Writer，不加入此屏障，不受续租、过期或接管影响。

## 实现

- 复用 Store 的跨进程文件锁基础，在状态文件旁维护独立 operation registry。短时间 admission lock 串行化检查及注册，每个有限操作独立持有 lifetime lock。操作实际返回后释放。进程退出后 OS 释放；后续检查清理失效记录。
- 依据规范化物理根目录判断祖先、子目录和同根重叠；不同项目及同一 Writer 代次可并行，不同代次的重叠根目录返回 writer_handoff_pending，客户端在旧任务结束后重试。该错误不会续期或撤销新租约。
- 注册前后分别校验实际租约 ID 及根目录，防止旧请求在换代后被放行；旧的无 ID 租约使用 owner 与获取时间的摘要，注册表不保存 owner 凭证。
- 文件新增、编辑、删除、Git 提交及工作流、同步 Exec（host/sandbox）、同步 Verifier（host/sandbox）、异步 Run 与 Verifier（host/sandbox）接入。异步任务在安装/启动前持有保护，失败清理，实际执行及完成处理后释放；原有取消、超时、权限检查保留。
- 诊断展示仍然活动的重叠旧代次操作类型、环境 ID、ADM 所在进程 PID、开始时间；即使当前没有 Writer 也可显示。PID 为持有保护的 ADM 进程，不一定是被执行子进程。不会把操作观测当作租约续期。

## 边界

屏障覆盖上述 ADM 有限任务的执行区间，不能阻止绕过 ADM 的外部程序、常驻 Process、旧版本客户端或从父进程脱离的任意宿主进程。操作返回与终态发布之间可能存在极短的保守拒绝窗口。强制崩溃时 OS 会释放保护句柄，但不能据此保证所有子孙进程都已退出；进程树回收与环境销毁/清理操作之间的互斥仍需后续专门验收。实际文件写入不会自动回滚。部署时应升级同状态文件的全部 ADM 组件。

## 验收

EADM Windows：同代次并发、不同代次重叠拒绝、兄弟根目录并发、多个旧操作未全部完成时拒绝、跨进程拒绝及进程退出恢复、新 Writer 文件和 Run 拒绝/恢复、诊断显示等专项测试通过；原有 Writer、Run、Verifier、Process 回归通过。浏览器模拟适配器三种规格各 306 项通过，包含旧代次交接信息显示。Linux/macOS 尚未运行本阶段专用屏障测试，未完成全量回归及发布验收。
