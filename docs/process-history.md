# Process 生命周期历史

常驻进程与 Writer 租约仍然独立。状态文件旁的 .process-history 目录保存每个 Process 的生命周期元数据，使用稳定的 registry 锁串行化原子记录更新；每条记录的独立 OS 文件锁代表当前 ADM 管理者持有记录。它不是 Writer 锁。启动前先记录，启动后记录 PID，结束后记录退出时间、退出码和原因。记录不含 argv、环境变量、日志正文或资源采样；日志仅在当前运行时内存中可读。

其他 Gateway 读取记录时，已结束的显示 exited，仍有其他持有者的显示 other_gateway，失去持有者且无退出记录的显示 owner_unavailable（状态未确认）。历史记录禁止通过旧 PID 停止或认领进程。管理者持有记录不等于已经验证实际进程健康。退出记录最多保留最近 256 条（仅对已确认终态且无持有者的持久记录裁剪）；未确认的记录保留供诊断。当前运行时仍保留其内存记录。DropEnvironment 停止当前管理的进程并清理该环境已确认终态的历史，未确认记录不自动删除。

Windows Job 回收沿用上一阶段实现。Linux 仍使用原进程组取消策略；原 Gateway 强制崩溃后不能保证整组退出。本阶段不自动认领或重启进程，不扫描并杀死记录中的 PID。后续 Linux containment 需通过受控 supervisor 或有权限的 cgroup 验证完整生命周期。

验收：Windows Store 独立实例记录所有权/终态/失联测试通过；Gateway 真实重启测试改为要求历史存在而非旧记录消失，同时禁止旧记录停止操作。Process 相关 Go 专项通过。浏览器三规格各 308 项通过，含历史失联记录禁用操作检查；之前权限确认测试两次偶发超时，复跑通过，仍待定位。Linux 尚未验收本阶段新记录机制。
