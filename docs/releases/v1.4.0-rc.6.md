# ADM v1.4.0-rc.6

基于 `v1.4.0-rc.5` 发布，保留原 RC 的 Windows Setup、Desktop Kit 与网关功能。

- Go MCP SDK 升至 `v1.8.0`。
- Gateway 的常驻 HTTP MCP Runtime 通过 `github.com/wanstu/mcp-center-core v0.1.2-rc.1` 连接外部 MCP，隔离入站/出站协议 Context。
- 兼容 ChatGPT 新版 MCP 协议连接 ADM、ADM 再连接旧版 MCP 服务的组合。
- 新增 `environment_mcp_status`、`environment_mcp_tools`、`environment_mcp_call` 嵌套真实 MCP 测试。
- 既有 stdio MCP 的执行许可、进程追踪与环境隔离保持原有行为；其他非 owner 的历史连接路径保留兼容实现，后续可继续逐步统一。
- 继续由 GitHub Actions 使用正式 tag 执行全量测试、跨平台构建并发布 RC，不上传开发机自编译产物。

部署注意：使用 GitHub Release 中与系统架构匹配的 CI 产物；备份现有 ADM 配置/数据。需要升级的是实际 ADM Gateway 服务进程，MCP Center 应先升级到对应的 RC。部署后分别通过 MCPHub (ladm) 与 MCP Center (eadm) 对同一数据库 MCP 做只读健康检查。
