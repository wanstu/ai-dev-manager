# ADM v1.4.1

基于 `v1.4.0` 的清理可靠性补丁。

- 修复嵌套 managed Git worktree 删除失败：当创建时的 source worktree 已被安全清理，子 worktree 不再依赖已经不存在的 SourceRoot；使用已验证的 GitCommonDir 执行 `git worktree remove`。
- 仍然检查匹配的 Writer、工作目录身份、所属 Git common directory、分支、dirty/unpublished 状态；不扩大 Agent 权限，不强制删除未保存代码。
- 新增真实 Git 回归测试，验证父 worktree 先删除、子 worktree 后删除，仍保留两个 Git 分支。
- 继承 `v1.4.0` 的 Core 正式依赖、Env 提升管理员权限限制、过期 Env 检查优化和 Desktop 安全清理功能。

继续由 GitHub Actions 执行跨平台 CI 和发布。请使用新版本正式产物手动部署。
