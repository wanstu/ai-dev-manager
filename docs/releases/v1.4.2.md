# ADM v1.4.2

基于 `v1.4.1` 的 worktree 清理安全检查补丁：

- 检查未提交代码时，除 Git 已跟踪和未跟踪文件外，也保护受 `.gitignore` 等规则忽略的本地文件。
- 本地 HEAD 在创建 worktree 时的 BaseCommit 之后有新提交时，必须对当前配置的远程仓库执行限时 `git fetch --prune`，并检查提交是否存在于远程分支历史中，不能使用未刷新的远程跟踪缓存。
- 远程不可达或无法验证时安全检查失败，保留 worktree；不会把检查失败当作已发布。
- 不接受已删除远程遗留的缓存分支作为“已发布”证据。
- 普通删除与批量清理共用这套检查；保留原来的运行状态 / writer / dirty / unpublished 等阻止条件。
- 桌面清理预览能提示 Git 忽略文件。

增加真实本地 Git bare remote 回归测试（已推送、远程删除、远程不可访问、忽略文件），继续由 GitHub Actions 验证完整测试与跨平台安装包。

注意：只是提升清理安全性，不修改历史 Env 的临时/永久属性，不自动清理任何历史目录。
