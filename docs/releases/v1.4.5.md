# ADM v1.4.5 — 管理页筛选与排序

基于 v1.4.4，优化 Desktop 与 Web 管理界面的日常资源查找；仅调整展示层筛选/排序，不改变权限、Git 安全检查、资源数据、后端读写行为或已配置的生命周期。

- **Environments**：名称/路径/ID/Workspace/owner 搜索，Workspace、持久化/临时/已过期/7 天内到期/无有效到期、managed worktree/普通 Env、有无 Writer 等条件可组合；支持最近活动、最早到期、名称、创建时间排序；一键重置。
- **Workspace**：按名称/路径/ID 搜索；按有无 Environment 筛选，并按 Environment 数量升降序或名称排序。
- **MCP**：在已有搜索及当前环境启用/需处理/未探测基础上，加 Transport 和新环境默认启用筛选。
- **Skills & Sources**：在原有 Source/可用性筛选基础上，加新环境默认启用及 Source 最近刷新状态筛选。
- **Runtime**：Verifier、Process、Run 的名称/ID/执行程序和状态筛选，保留原始列表和操作权限。
- **执行权限**：Allowed executable / Blacklist 文本搜索，保持执行统计、授权记录等现有筛选。
- 各面板一键重置、显示过滤后计数，筛选是只读行为，不会批量选择或触发任务。

新增 **management_snapshot.managed_worktree_environment_ids**（只读 ID 数组），类型筛选以 Gateway 的受管理 worktree 记录为准，不通过路径或 retention policy 猜测；如果连接尚未升级的 Gateway，类型筛选自动禁用，避免误导。

测试：前端纯数据模型单测、Go management 快照真实 Git 测试、前端 DOM 合约和原有浏览器冒烟测试；额外提供 filters 场景在 1120×760、820×560、125% 缩放下检查组合筛选、重置与无横向溢出。

通过 GitHub Actions 构建官方跨平台产物；请使用官方 Release 安装包手动升级 Desktop 与 Gateway。
