# ADM v1.4.4

修复已过期临时 Environment 被缓存的上游 MCP 会话长期阻止安全回收的问题。

- 将缓存的 MCP session 与真实进行中的工具调用区分：过期临时 Env 的 idle session 不再被误判为“正在使用”；非过期 Env 的原有保护保持不变。
- `Status`、`ListTools`、`CallTool` 全程跟踪实际在途 MCP 操作；执行过程中保留回收阻止条件 `mcp_operation_in_flight`。
- Gateway 启动时不再为已过期的临时 Env 预连接 MCP。
- 监控循环不再自动维护过期 Env 的 MCP 链接，并释放闲置的缓存 session；如存在在途操作或正在进行的后台探测，则延迟到操作结束。
- 工作目录清理仍要经过原有的到期判定、Git dirty/ignored 文件、未发布提交、Writer/运行任务等安全检查，不使用 force，不修改历史 TTL 和普通 Workspace。
- 新增真实测试：空闲/实际在途调用区分、连接关闭后能正确回收 managed worktree 且保留 Git 分支、避免对过期 Env 重新建立连接、未到期 Env 仍受保护。
- 仅由 GitHub Actions 构建安装包并发布。管理员手动重新部署 Gateway 后再运行过期 Env 清理预览；不会自动删除任何历史 Worktree。
