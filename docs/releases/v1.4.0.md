# ADM v1.4.0 正式版

基于已上线验证的 `v1.4.0-rc.6`，包含后续 Env 生命周期和清理优化。

- ADM Gateway 依赖正式 MCP Center Core `v0.1.2`，Go MCP SDK `v1.8.0`；保持已验收的新旧协议嵌套 MCP 调用修复。
- 修复过期临时 Environment 检查缓慢：先按类型与到期时间筛选，再只对候选执行 Git 安全检查；保留清理时原有的 dirty/unpublished/runtime 保护。
- Desktop 开放闲置 managed worktree 安全清理入口；预览默认不选中候选，必须手动勾选，执行前重新校验；保留 Git 分支。
- 权限限制：Agent 只能创建临时 Env；`environment_temporary_promote` 仅 Admin MCP 可以调用，Agent 即使知道 owner_id 也无法提升为持久化。
- 仍保留 Admin 的环境创建、提升和清理能力。

请使用 GitHub Actions 构建的正式 Release 产物。建议备份 ADM 持久化配置和数据，再由管理员手动重新部署 Desktop/Gateway。
