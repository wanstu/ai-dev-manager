DESKTOP SETTINGS

设置

Desktop 壳层设置；不改变 ADM Core、Environment、Agent Runtime 或连接授权。

Managed worktrees

Core / Gateway shared configuration

配置目录会自动登记为受保护的 system Workspace；存在 managed worktree 时不会移动根目录。

ADM 配置

用户级配置 + 应用目录覆盖
用户级 .env~/.config/adm/.envCLI 与 Desktop 都会读取，适合保存 ADM_V2_URL、ADM_ADMIN_API_KEY 等客户端连接变量；旧 ADM_V2_ADMIN_API_KEY 仅兼容读取。
应用目录 .env<adm / adm-desktop 可执行文件目录>/.env同名变量会覆盖用户级 .env，适合便携部署或单个安装实例的覆盖配置。
Desktop 连接~/.config/adm/desktop-connections.json保存 Desktop 连接 profile。UI 不回显 Admin Key，但保存的客户端连接仍可继续使用。

优先级：显式进程环境变量 > 应用目录 .env > ~/.config/adm/.env。Remote access 页面设置的服务端 Admin/Agent Key 只保存哈希，不会写入这些 .env 文件。

添加连接

填写 Remote access 中服务端 /admin/mcp 使用的同一把 Admin Key；密钥不会在重新打开编辑窗口时回显。

连接凭据说明

Admin Key 只用于 Desktop / CLI 管理连接（/admin/mcp）；Agent Key 只用于 Agent 的 /mcp，不能填在这里。

CLI 可在 ~/.config/adm/.env 配置 ADM_V2_URL 与 ADM_ADMIN_API_KEY。应用可执行文件同目录的 .env 优先级更高。

仅支持本机 loopback ADM URL 自动启动。连接资料保存在 ~/.config/adm/desktop-connections.json；用户级环境配置位于 ~/.config/adm/.env。
