# 23-01 — MCP/Skill provisioning and diagnostics

Requirements: ADM-GOAL-001/002, ADM-CORE-003/004/012/015/018/019/020, ADM-CLI-001, ADM-GW-001/003, ADM-MGMT-001, ADM-NONGOAL-001.
New prerequisites: none.

## Objective

Close the practical CLI gaps around MCP import/provisioning and MCP/Skill diagnostics by projecting already accepted Admin MCP capabilities into the normal `adm` CLI.

This plan must not redesign MCP import/runtime semantics, Skill identity/refresh semantics or the management authority boundary.

## Task 1 — Shared MCP import content input helper

Likely files:

- `cmd/ai-dev-manager/main.go`
- `cmd/ai-dev-manager/main_test.go`
- focused CLI/Admin-MCP acceptance tests as needed

Refactor `mcp import-preview` and `mcp import-apply` to resolve content through one CLI-only helper.

Supported mutually exclusive sources:

- `--json-or-jsonc CONTENT`;
- `--file PATH`;
- `--stdin`.

Rules:

- exactly one content source is required;
- `--file` is read by the local CLI process before the Admin MCP call;
- `--stdin` is explicit and must fail clearly if stdin is an interactive terminal rather than blocking unexpectedly;
- preview and apply use identical source resolution;
- read/selection errors occur before any Admin MCP mutation;
- do not echo raw import content in errors;
- preserve existing importer validation, credential-reference conversion, atomic apply and no-existing-Environment-selection-mutation semantics;
- no raw import blob persistence or new import format.

The existing inline option remains valid. Do not change conflict/default/source-scope semantics.

## Task 2 — MCP owner-runtime inspect/refresh CLI parity

Likely files:

- `internal/adminmcp/client.go`
- `cmd/ai-dev-manager/management_backend.go`
- `cmd/ai-dev-manager/main.go`
- CLI/Admin-MCP tests

Add thin Admin MCP client wrappers and CLI commands for the existing shared tools:

- `adm mcp inspect --id MCP_ID --environment-id ENV_ID`
- `adm mcp refresh --id MCP_ID --environment-id ENV_ID`

Keep existing:

- `mcp probe` = global transient management probe;
- `mcp status` = selected-Environment one-shot probe.

Update help so all four meanings are explicit.

Acceptance semantics:

- inspect returns sanitized `MCPRuntimeInspection`/equivalent existing structured result and does not connect, Ping or refresh;
- refresh explicitly performs the existing owner-runtime reconnect/Ping/inventory refresh path;
- neither requires writer acquisition;
- refresh never calls an MCP business tool, changes the global definition, changes Environment selection or creates a second observed-state store;
- disabled/unconfigured/broken MCP failures remain local to that MCP.

Do not add arbitrary raw tool-call support to CLI in this plan.

## Task 3 — Skill source update and availability CLI parity

Likely files:

- `cmd/ai-dev-manager/management_backend.go`
- `cmd/ai-dev-manager/main.go`
- existing `internal/adminmcp.Client` only if a small missing wrapper is discovered
- CLI/Admin-MCP tests

Add/extend:

- `adm skill source-update --id SOURCE_ID --root PATH [--support-root PATH ...] [--default=true|false]` using the existing source update operation;
- make `skill source-add --support-root` repeatable so the CLI represents the canonical `[]string` support-root model;
- `adm skill availability` for global catalog structural availability;
- `adm environment skill list --environment-id ENV_ID` for Environment-specific availability;
- `adm environment skill inspect --environment-id ENV_ID --skill-id SKILL_ID` for one Environment-specific Skill availability result.

Rules:

- source update never refreshes implicitly;
- source refresh remains explicit;
- support roots are repeated flags, not a comma-encoded alternate model;
- `skill list` remains catalog inventory and is not relabeled as availability;
- global structural availability remains independent of Environment enablement;
- Environment list/inspect enforces Environment selection facts already defined by Core;
- availability commands do not read Skill instructions/support-file contents, execute Skills or mutate catalog/source state.

Update help so Source configuration, refresh, catalog inventory and availability are visibly distinct.

## Task 4 — Real CLI/Admin-MCP acceptance

Use the existing production CLI target path against a real disposable HTTP Gateway/Admin MCP where practical. Do not satisfy this plan only with direct helper mocks.

P01 — MCP import preview from a temporary JSON/JSONC file succeeds and returns the same normalized/sanitized candidate semantics as inline content.

P02 — MCP import apply from redirected stdin succeeds; Windows shell-native quoting of inline JSON is no longer required for file/stdin workflows.

P03 — zero or multiple import content sources fail before apply and leave catalog state unchanged.

P04 — imported literal credential-bearing values remain absent from persisted definitions and returned normal diagnostics; reference requirements remain visible.

P05 — `mcp probe`, `status`, passive `inspect`, and explicit `refresh` are separately callable and their help/side-effect boundaries match `23-CONTEXT.md`.

P06 — passive MCP inspect makes no upstream request when no prior owner observation exists. Explicit refresh may connect/Ping/list tools but invokes zero business tools.

P07 — MCP refresh does not modify the definition or Environment enabled-ID set.

P08 — Skill source add/update round-trips multiple support roots and update does not refresh until explicit `source-refresh`.

P09 — global `skill availability` reports structural state independently from Environment selection; Environment Skill list/inspect report selected/disabled/broken state without artifact-content reads.

P10 — one broken MCP/Skill/source remains operation-local; plain non-Git Workspace/Environment management remains usable without MCP/Skill configuration.

P11 — new commands fail through the normal Admin MCP no-fallback path when the selected management target is unavailable.

P12 — successful new commands emit valid JSON to stdout; help remains text and failures remain non-zero through the existing CLI error path.
