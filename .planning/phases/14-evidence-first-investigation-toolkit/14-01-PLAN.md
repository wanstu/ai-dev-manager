# 14-01 Plan — Endpoint Evidence Resolution

## Goal

Add a small evidence-first helper for endpoint investigation. Given an Environment, target URL/path, and optional HTTP method, ADM returns bounded static evidence for likely route definitions without running project code.

## Requirements

- Normalize full URLs into path-only targets and strip query/fragment.
- Search exact route literals and conservative dynamic-route variants such as `:id`, `{id}`, `<id>`, and `[id]` for numeric/UUID/hash-like segments.
- Include evidence records with file path, line number, matched query, score, and reason tags.
- Return `confidence` and `uncertainties` explicitly.
- Bound max files, max matches, and per-file bytes.
- Skip obvious generated/dependency directories.
- Be side-effect-free: no writer requirement, no command execution, no network, no verifier, no process/run/MCP operation.
- Expose through the Agent-facing Gateway as `investigate_endpoint`.

## Implementation notes

- Add shared model structs in `internal/model`.
- Add app service method `InvestigateEndpoint`.
- Add Gateway input/tool wrapper.
- Add focused app and Gateway tests.
