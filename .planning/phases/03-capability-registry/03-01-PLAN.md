# Plan 03-01 — MCP catalog + Skill discovery vertical slice

## Objective

把 Phase 2 的“配置已经能落盘并解析”推进成“共享能力可以自动发现并稳定消费”：Global/Profile/Project MCP 形成 Catalog；Global/Profile/Project Skill roots 自动发现 `SKILL.md` 并参与现有四层 resolver。

## Scope Guard

本 Plan 只做：

- `SkillRoots` 配置字段与 JSON persistence
- Skill discovery / layer expansion
- MCP `EnvRefs` persistence + resolver merge
- MCP Catalog（不连接进程）
- ConfigService 集成 discovery
- tests / GSD transition

明确不做：

- 启动/连接 MCP Server
- MCP health network probe
- 读取 Codex/Claude/DevSpace 外部配置格式
- 执行 Skill 内容
- Agent/Subagent registry
- Shell/Git/Docker/Runtime execution
- UI

## Task 2 — Implement Skill discovery

**Create:**
- `internal/skill/discovery.go`
- `internal/skill/discovery_test.go`

**API direction:**

```go
func ExpandLayer(layer model.ConfigLayer, baseDir string) (model.ConfigLayer, error)
```

**Rules:**

- clone layer first。
- root path resolution:
  - `~` / `~/...` -> user home
  - absolute -> direct
  - relative -> baseDir
- configured root 必须存在且是目录。
- recursively find `SKILL.md` with standard library `filepath.WalkDir`。
- do not follow directory symlinks。
- Skill ID = parent directory basename。
- later root same ID wins。
- explicit `layer.Skills[id]` wins after discovery。
- discovered Skill default Enabled=nil（inherit/no explicit enable decision）。
- no YAML parser in this Phase。

**Structured errors:**
- invalid_root
- root_not_found
- walk_failed

**Tests:**
- global root discovers gsd。
- nested root works。
- later root overrides same ID。
- explicit Skill overrides discovered。
- missing root structured error。
- input not mutated。
- relative root resolves against baseDir。

## Task 4 — Implement MCP Catalog

**Create:**
- `internal/mcp/registry.go`
- `internal/mcp/registry_test.go`

**API direction:**

```go
type Registry struct { ... }
func FromEffective(cfg model.EffectiveConfig) *Registry
func (r *Registry) Get(id string) (Entry, bool)
func (r *Registry) List() []Entry
func (r *Registry) Enabled() []Entry
```

**Entry:**
- merged MCP definition
- Source
- EnabledSource
- Health = `unprobed`
- Capabilities extension slice, empty for now

**Rules:**
- deterministic alphabetical List/Enabled。
- disabled definitions remain in List。
- `Enabled()` treats nil Enabled as enabled-by-default only if Context confirms; otherwise explicitly define/test one default semantic and document it. Prefer preserving current tri-state and expose helper rather than silently inventing runtime behavior.
- no network/process calls。

**Tests:**
- Global inherited in two workspace effective configs -> both catalogs have entry。
- Project disable retained in List with project EnabledSource。
- Project private only A。
- deterministic order。
- Health unprobed。
