| Boundary | Description |
|----------|-------------|
| client→Gateway | Agent tools cross into Gateway handler layer; untrusted MCP endpoint URLs and header values may be supplied |
| Gateway→External MCP | connectExternalMCP resolves secrets and connects to external MCP; resolved endpoint must not leak |
| Gateway→CLI/Management | Health status returned to management surfaces must not expose secret values |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Information Disclosure | connectExternalMCP error messages | HIGH | mitigate | connectExternalMCP is refactored to never include endpoint URL in error messages; callers receive error_kind + mcp_id only |
| T-03-02 | Information Disclosure | Health status / inspect output | HIGH | mitigate | Resolved endpoint values never stored, returned, or included in error text; os.ExpandEnv called only at connect boundary |

| T-03-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new package installs in this phase — all dependencies already in go.mod |
