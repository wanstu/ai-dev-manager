# Plan 05-01 — Git/worktree + verifier vertical slice

## Objective

实现一个真实开发闭环：Native Runtime 修改代码后，可以获得结构化 Git 状态/差异，并运行项目声明的 test/build verifier；同时支持安全 managed worktree create/list/remove。

## Scope Guard

本 Plan 只做：

- VerifierDefinition model + v1 JSON persistence + resolver
- Runtime Git status/diff/branch
- managed worktree list/create/remove
- verifier runner
- Git/Test capability exposure
- end-to-end temp repo test
- GSD transition

明确不做：MCP Host、Docker、Agent、UI、任意 unified patch parser。

## Task 1 — Verifier model/persistence/resolution

**Modify:**
- `internal/model/config.go`
- `internal/config/resolver.go`
- `internal/config/store.go`
- tests

Add `VerifierDefinition`, `ResolvedVerifier`, `ConfigLayer.Verifiers`, `EffectiveConfig.Verifiers`.

Resolver semantics:
- stable ID validation。
- new definition deep copy。
- higher non-empty Kind/Executable/Cwd replace lower。
- non-nil Args replace lower even when empty slice intentionally clears args。
- non-zero TimeoutSeconds replace lower。
- Enabled tri-state updates EnabledSource。
- body changes update Source。

Store v1 adds optional `verifiers` map; old v1 remains compatible。

## Task 2 — Git capability

**Create:** `internal/runtime/git.go`, tests.

All Git calls use `Native.Exec(Command{Executable:"git", ...})` and fixed Workspace cwd。

Implement:
- status porcelain `-z` parser
- diff name list + patch
- branch show-current
- worktree porcelain parser

Non-zero Git exit becomes structured GitError with stderr summary and exit code, while policy/tool errors remain RuntimeError。

## Task 3 — Managed worktrees

Managed root:
`filepath.Join(filepath.Dir(runtime.root), ".ai-dev-manager-worktrees", safeWorkspaceID)`.

Implement safe name/branch validation, create/list/remove.

Create command:
`git worktree add -b <branch> <target> HEAD`

Remove command:
`git worktree remove <target>`

No force by default。

Tests with real temp Git repo and actual git executable located during test setup。

## Task 4 — Verifier runner

**Create:** `internal/runtime/verifier.go`, tests.

- Runtime snapshots resolved verifiers at `NewNative` construction。
- `RunVerifier(id)`。
- `RunVerifiers(ids...)` sorted when ids empty。
- disabled -> skipped。
- nil/true -> runnable。
- timeout seconds maps to Command.Timeout。
- non-zero exit -> `failed` result, not transport error。
- timeout -> failed result with TimedOut=true; policy/tool/cwd errors remain returned errors。

## Task 5 — Capabilities

Extend capability constants:
- `git.status`
- `git.diff`
- `git.branch`
- `git.worktree`
- `verify.run`

Expose Git capabilities only when execution mode supports exec and git is policy-allowed (Standard) or Full. Expose verify.run for Standard/Full when at least one verifier exists; execution may still report a tool-policy error per verifier if its executable is not allowed.

## Task 6 — End-to-end acceptance

Create temp repo with committed source file and real Git identity scoped to repo.

Policy ToolPaths:
- git -> located git executable
- helper -> current test binary

Flow:
1. New Native runtime.
2. Edit tracked file.
3. GitStatus contains modified path.
4. GitDiff files/patch contains modification.
5. test verifier passes.
6. build verifier passes.
7. failing verifier test separately returns failed + exit code.

## Task 7 — Verification and scope review

Run gofmt, `go test ./...`, `go vet ./...` and verbose Git/worktree/end-to-end tests.

Search `internal/` for MCP server/network host, Docker, Agent, Wails scope leaks。

## Task 8 — Auto transition

Because `workflow.auto_advance=true`, after all Phase 5 exit criteria pass:

1. move WORK-03 / VERIFY-01..03 and completed EXEC/RUN portions to Validated appropriately。
2. record Git/worktree/verifier decisions。
3. mark Phase 5 complete。
4. create Phase 6 Context/Plan。
5. immediately execute Phase 6 without waiting for a new user prompt unless blocked。

## Definition of Done

- real Git status/diff/branch passes。
- real managed worktree create/list/remove passes。
- test/build verifiers persisted/resolved/run structured results。
- failing verifier is attributable by ID/kind/exit code。
- full modify→diff→verify test passes。
- all tests/vet green and no scope leak。
