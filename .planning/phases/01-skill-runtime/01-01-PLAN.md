# Phase 01 Plan 01-01 — Real Skill Vertical Slice

## Objective

Make one real global GSD Skill discoverable and consumable through ADM for one enabled Environment, while proving a disabled Environment cannot access it.

## Tasks

1. Inspect the actual global GSD Skill installation used on this machine and define the minimum artifact contract required by that Skill.
2. Replace/correct the current text-only Skill catalog model with a real Skill source/discovery model:
   - explicit configured roots only;
   - stable discovered identity;
   - canonical path/source metadata;
   - no arbitrary host filesystem exposure.
3. Keep Environment Skill selection as the authorization gate.
4. Add application/service methods that resolve enabled Skills to actual artifacts/content.
5. Add Agent Gateway capability for Environment-scoped Skill discovery and content access. Do not require a separate MCP connection per Environment.
6. Update CLI/Desktop management only enough to configure/inspect the real Skill source model; no UI redesign.
7. Add negative tests:
   - unconfigured root is not scanned;
   - disabled Skill cannot be accessed through another Environment;
   - path escape/supporting-file access outside the explicitly configured Skill artifact/support roots is rejected;
   - missing/broken Skill artifact reports a structured/local failure and does not break unrelated tools.
8. Add positive acceptance:
   - real GSD Skill discovered from its actual global path;
   - two enabled Environments can consume the same installation;
   - one disabled Environment cannot;
   - a real Gateway client reads the GSD Skill through ADM.
9. Run full verification.
10. After acceptance, use the GSD Skill through ADM to review/update `.planning/STATE.md` and prepare Phase 02.

## Required Verification

- focused catalog/skill tests
- focused Gateway Skill tests
- `go test ./...`
- `go vet ./...`
- `git diff --check`
- real Gateway client acceptance against the actual GSD Skill installation

## Non-goals

- GSD phase execution inside ADM
- Agent Run lifecycle
- verifier implementation
- MCP runtime expansion
- worktree isolation
- process/log/port manager
- Desktop polish/package work
