# Plan 02-01 — Persistent config + workspace registry vertical slice

## Objective

实现 Phase 2 的完整最小闭环：多个 Workspace 可持久化注册，Global/Profile/Project 配置可从磁盘加载，并复用 Phase 1 resolver 产出 `EffectiveConfig`。

## Scope Guard

本 Plan 只做：

- JSON persistence schema
- Config Store
- Workspace Registry
- WorkspaceConfigService orchestration
- Project config Git boundary
- Unit/integration tests
- Planning transition

明确不做：

- MCP 启动/health check
- Skill 文件扫描或 SKILL.md 解析
- Shell / Git command execution
- Runtime process lifecycle
- Docker
- Wails/UI
- CodexPro/DevSpace adapter

## Task 1 — Define persistence schema without polluting domain model

**Files:**
- `internal/config/store.go`
- 必要时小幅补充 `internal/model/config.go`

**Implement:**
- schema version constant = 1
- user config DTO: version + global layer data + workspaces
- layer DTO: MCPs / Skills / Policy，不持久化 Scope
- profile/project config DTO
- encode/decode conversion helpers

**Rules:**
- persistence DTO 与 domain model 可以分离，避免 JSON schema 绑死 Core 类型。
- Runtime Override 不进入任何持久化 DTO。
- 不加入 PID/port/process state。
- 不直接建立 secret store。

**Tests:**
- v1 round-trip
- missing file default
- malformed JSON
- newer unsupported version

## Task 2 — Implement atomic Store

**Files:**
- `internal/config/store.go`
- `internal/config/store_test.go`

**API direction:**

```go
type Store struct {
    root string
}

func NewStore(root string) *Store
func DefaultRoot() (string, error)
func (s *Store) LoadUserConfig() (...)
func (s *Store) SaveUserConfig(... ) error
func (s *Store) LoadProfile(id string) (model.ConfigLayer, error)
func (s *Store) SaveProfile(id string, layer model.ConfigLayer) error
func (s *Store) LoadProject(workspacePath string) (model.ConfigLayer, error)
func (s *Store) SaveProject(workspacePath string, layer model.ConfigLayer) error
```

命名可调整，但职责不变。

**Atomic write:**
1. mkdir parent
2. create temp in target dir
3. encode/write
4. sync/close
5. rename target
6. cleanup temp on failure

**Security/safety:**
- profile ID 拒绝空值、路径分隔符、`.` / `..`。
- Project path 只基于传入 workspace root 拼 `.ai-dev-manager/config.json`。
- error 不打印完整 env 内容。

## Task 3 — Implement Workspace Registry

**Files:**
- `internal/workspace/registry.go`
- `internal/workspace/registry_test.go`

**Behavior:**
- Add
- Get
- List
- Update
- Remove

**Add:**
- path 必须非空、绝对、存在且是目录。
- 规范化后禁止重复。
- ID 使用 `crypto/rand` 生成 `ws_` + 32 hex chars。
- ProfileID / RuntimeID Phase 2 只保存，不验证对应 runtime 是否存在。

**Update:**
- ID 不变。
- 新 path 仍做 duplicate validation。

**Windows path comparison:**
- 使用 clean/abs 后的 canonical path。
- 在 Windows 语义下 case-insensitive；测试需覆盖大小写差异。
- 不用字符串前缀判断目录安全。

## Task 4 — Implement WorkspaceConfigService

**Files:**
- `internal/workspace/service.go`
- `internal/workspace/service_test.go`

**Flow:**
1. Get Workspace by ID.
2. Load user Global layer.
3. Workspace.ProfileID 非空时 LoadProfile；引用不存在必须报错。
4. LoadProject；文件不存在视为空 project layer。
5. 接受可选 in-memory Runtime Override。
6. 调用 `config.Resolve`。
7. 返回 `EffectiveConfig`。

**Critical tests:**
- Workspace A/B 共享 Global，但 Project override 互不影响。
- Project disables Global MCP after disk round-trip.
- Project Skill overrides Global Skill path.
- Runtime override still wins.
- Runtime override is not written to disk.
