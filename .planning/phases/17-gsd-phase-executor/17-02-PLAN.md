# Phase 17 Plan 17-02 — Verified GSD State Transition & Auto-advance

## Objective

在 17-01 已验证的 GSD execution/review 之后，只有当 `review.decision=pass` 时，确定性地推进 `.planning/STATE.md` 到仓库中已经存在的下一个 executable plan；如果下一步规划工件不存在，则记录 blocked/no-next-plan 并停止，不猜测、不创建。

## Transition Rules

1. `review=fail`：不修改 STATE，Run 仍是 completed，advance result = not_advanced/review_failed。
2. `review=pass`：读取当前 Plan provenance，并查找下一 executable plan。
3. 同一 Phase：只接受当前 phase directory 中 plan id 大于当前 plan id 的最小一个，例如 `17-01 -> 17-02`。
4. 同一 Phase 无后续 plan 时：只检查 `phase+1`，不跳号。
5. 跨 Phase：要求唯一 `NN-*` directory、`NN-CONTEXT.md` 和至少一个 `NN-XX-PLAN.md`；取最小 plan id。
6. Phase/Plan display title 必须从目标 CONTEXT/PLAN 的一级标题显式解析，不从目录 slug 猜。
7. 下一 Phase/Plan 工件缺失或歧义：不修改 STATE，advance result = blocked，workflow 不伪报下一步。
8. STATE 更新使用现有 `files.edit` Runtime operation，对 Current Position 中 exact `Phase:` / `Plan:` / `Status:` 文本做单次替换；Runtime policy remains authoritative。
9. 自动推进只修改 Current Position，不自动篡改 PROJECT/ROADMAP requirements/history；这些由执行 spec 或后续人工/LLM plan 明确维护。

## Audit Model

RunStatus 增加可选：

- `advance.status`: `advanced | blocked | skipped`
- `advance.from_phase`
- `advance.from_plan`
- `advance.to_phase`
- `advance.to_plan`
- `advance.reason`

This is observed audit data; STATE is the durable project position.

## Implementation Steps

1. 扩展 workflow RunUpdate / RunStatus 保存 `AdvanceResult`。
2. 为 WorkflowExecutor 增加可选 post-review `CompletionHandler`，verify workflow 不使用。
3. GSD workflow 配置 `GSDAdvancer`。
4. GSDAdvancer 通过 Runtime Adapter read/tree/edit 查找下一 plan 并 exact-update STATE。
5. pass-only gate：review fail/Run error/cancel 永不调用 state advance。
6. Tests：
   - same-phase `17-01 -> 17-02`
   - next-phase `17-02 -> 18-01`
   - missing next context/plan => blocked + STATE unchanged
   - review fail => skipped + STATE unchanged
   - ambiguous next phase => blocked
   - missing edit capability => blocked rather than unsafe fallback
7. Process-level CLI acceptance observes completed Run + advance result and verifies STATE file changed to the expected pre-existing target.
