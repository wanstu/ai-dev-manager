## Scope

`v1.0.0` is the first stable local ADM release after the V2 core/RC dogfood cycle. It includes the validated local development control plane for external Agents plus the Desktop management surface and release automation established through the Phase 16/17 closeout.

This release does not add installer, updater, signing, notification, or non-loopback remote Admin MCP enablement. Those remain post-1.0 work only when concrete dogfood evidence proves they are needed.

## GitHub release behavior

The existing CI workflow runs on `v*` tags. Pushing `v1.0.0` should run:

- Windows tests/vet/Desktop smoke build;
- CLI cross-build for Linux, macOS, and Windows;
- checksum generation;
- GitHub Release publication through `softprops/action-gh-release`.

Because `v1.0.0` contains no hyphen, the workflow should mark it as a stable release rather than a prerelease.

## Known limitations retained after 1.0

- No installer/updater/signing/notifications are included.
- Non-loopback remote Admin MCP remains disabled until authentication/TLS/Host-boundary semantics are defined.
- Long synchronous `pjadm.exec` can still hit the outer ChatGPT/tool timeout; long verification should use async `run_start` + `run_status`, whose running-output snapshot was validated live.
- The optional real host GSD Skill HTTP acceptance test remains skipped unless `ADM_REAL_GSD_SKILLS_ROOT` and `ADM_REAL_GSD_SUPPORT_ROOT` are set.

## Release decision

Proceed with `v1.0.0` tag and publish after committing this closeout record. Do not create additional installer/updater/signing work for this release.
